# 🧹 Cleaned Data

This folder contains information about the dataset after data-cleaning and validation.

Cleaning included:

- Date-type conversion
- Customer-name creation
- Column renaming
- Removal of unnecessary index columns
- Removal of the high-missing-value merchant ZIP-code field
- Duplicate checks
- Transaction-value validation

**Final Rows:** 1,296,674  
**Final Columns:** 21  
**Missing Values:** 0  
**Duplicate Records:** 0

The cleaned dataset is hosted on Google Drive because of its large file size.
