# ⚙️ Feature-Engineered Data

This folder contains information about the final analytical dataset created from the cleaned data.

The dataset contains 12 additional features covering:

- Time-based transaction analysis
- Customer age and age groups
- Transaction amount groups
- Weekday/weekend behavior
- Time-of-day analysis
- Geographic segmentation

The feature-engineered dataset was used for the project's EDA, SQL analysis, and reporting.

The actual file is hosted on Google Drive because of its large size.
