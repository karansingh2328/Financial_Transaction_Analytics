# 📁 Raw Data

This folder contains information about the original financial transaction dataset used in the project.

The actual dataset is hosted on Google Drive because its file size exceeds GitHub's regular individual-file limit.

### Dataset

**Source:** Kaggle  
**Rows:** 1,296,674  
**Columns:** 24  
**Domain:** Financial Transactions  
**Period:** January 2019 – June 2020

> **Note:** Google Drive may display a warning stating that it cannot scan this large file for viruses. This is a standard Google Drive message for large files. The file can still be downloaded normally.
